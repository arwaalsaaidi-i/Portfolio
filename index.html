02 / CASE STUDY

MICROSOFT POWER BI

Saudi Arabia Economic Indicators Dashboard

An interactive Power BI dashboard built from World Bank data to explore economic and development indicators for Saudi Arabia.

Project Overview

This project focuses on analyzing Saudi Arabia's economic and development indicators using data sourced from the World Bank.

The dashboard allows users to explore multiple indicators over time through interactive filtering and visualizations.

Dataset

The project uses World Bank indicators covering multiple areas of Saudi Arabia's economy and development.

  • Macroeconomic indicators
  • Trade and investment
  • Population and demographics
  • Education and health
  • Energy and natural resources
  • Public finance and development

The original dataset contained indicator names alongside multiple year columns. To make the data suitable for analysis and interactive filtering in Power BI, it was transformed into a structured format using Power Query, with each record representing an indicator, year, and corresponding value.

Data Preparation & Power Query

I used Power Query to prepare and transform the World Bank dataset before building the dashboard. The preparation process focused on correcting the structure and data types, removing unnecessary records and errors, and converting the dataset into a format suitable for analysis.

  • Changed data types to ensure consistency across fields.
  • Removed unnecessary bottom rows from the source data.
  • Promoted the appropriate row to column headers.
  • Replaced values where required to improve consistency.
  • Unpivoted the year columns to convert the dataset from a wide format into a structured long format.
  • Removed errors that could affect the analysis.
  • Extracted relevant text from fields where required.

Final structure:

Country Name | Series Name | Attribute (Year) | Value

Data Modeling, DAX & Dashboard Development

After preparing the dataset, I structured the data for analysis in Power BI and created DAX measures to support the interactive dashboard.

The measures used the AVERAGE aggregation to calculate indicator values based on the selected filters. This approach was used because the dataset contains annual observations, making an average aggregation more appropriate than summing indicator values.

The dashboard includes an Indicator Slicer that allows users to select individual indicators and dynamically explore their values and historical trends. KPI cards display the selected year and indicator value, while the main trend visualization presents the selected indicator across the available years.

The dashboard was designed to provide a simple and interactive way to explore multiple economic and development indicators within a single analytical view.
